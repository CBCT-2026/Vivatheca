## How to review

A fluent Japanese-speaking clinician reads the page in Japanese, fixes the text in `app/i18n/dictionaries/ja.ts` or the page's `ja.js`, then records the review:

```
pnpm i18n:status --mark-reviewed --by "Name" --prefix learn.        # dictionary keys under learn.
pnpm i18n:status --mark-reviewed --by "Name" --page head-neck/scc   # one static page
```

The disclaimer translations (`disclaimer.*`) need this review before public launch.
